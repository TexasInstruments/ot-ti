# OpenThread

This directory contains the platform drivers necessary to run Radio Co-Processor OpenThread on the Texas Instruments CC13XX_CC26XX family of
connected MCUs.
These drivers use the TI SimpleLink™ SDK for the RTOS enabled platform drivers.

## Important

Be aware that TI SDK does not support all use cases.
* It's possible to open `openthread.syscfg` project with SysConfig 1.24.1 [download link](https://www.ti.com/tool/download/SYSCONFIG/1.24.1.4189)
* we had to patch the `openthread.syscfg` to support HIGH PA
* we had to patch the SDK in order to support Tx power from -20 to 20 dBm (with gap in the table) `patch/0001_expand_power_table_pa20_10.patch`
* we had to generate source code generated by TI build tool `<YOUR_PATH>/dolphin-linux-fw-ccxx52-thread-ot-ti/build/src/syscfg/<GENERATED_FILES>`
    * ti_devices_config.c
    * ti_radio_config.c
    * ti_radio_config.h
    * ti_drivers_config.c
    * ti_drivers_config.h
* we use the source code generated by TI build tool and we have added bugfix in order to be able to build source code `<YOUR_PATH>/dolphin-linux-fw-ccxx52-thread-ot-ti/src/syscfg/<GENERATED_AND_PATCHED_FILES>`

## Toolchain

In a Bash terminal, follow these instructions to install the GNU toolchain and other dependencies.

```console
$ cd <path-to-ot-ti>
$ git submodule update --init --recursive
$ ./script/bootstrap
```

\***\*Attention:\*\*** In case of error, restart command  `./script/bootstrap`.

## Building

In a console terminal:

```console
$ ./script/build LP_CC1352P7_4 -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DOT_DIAGNOSTIC=ON -DOT_APP_CLI=OFF -DOT_APP_NCP=OFF -DOT_FTD=OFF -DOT_MTD=OFF
```

\***\*Attention:\*\*** In case of error, restart the previous command or run `cmake --build build`.

## Flash Binaries

When the build completed successfully, the RCP `bin` files may be found in `<path-to-ot-ti>/build/bin/ot-rcp.bin`.

In a console terminal:
```console
$ scp build/bin/ot-rcp.bin  root@192.168.0.4:/lib/firmware/ccxx52
```

In a CCU console terminal:
```console
$ cd /lib/firmware/ccxx52/
$ pkill -9 otbr-agent
$ ./ccxx52frmw-update.sh ot-rcp.bin
$ SERIAL_INTERFACE="/dev/ttymxc2"
$ otbr-agent -d 5 -v -I wpan0 -B eth0 spinel+hdlc+uart://$SERIAL_INTERFACE?uart-baudrate=115200 trel://eth0 &

// Example of diagnostic command
$ ot-ctl version
$ ot-ctl diag start
$ ot-ctl diag channel 11
$ ot-ctl diag power 20
$ ot-ctl diag send 127 100
```
